# 脑洞发电官网

原生 HTML、CSS、JavaScript 单页官网，保留黑金视觉风格。图片位于 assets/；咨询后端为 Cloudflare Pages Functions 的 functions/api/lead.js。无需 npm 安装或前端构建。

## 本地预览

在本目录执行：

```powershell
python -m http.server 8088 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8088。按 Ctrl+C 停止。此静态服务不执行 Pages Functions，表单提交会显示失败提示；不要在本地填写真实个人信息。开发验证应拦截 /api/lead 并使用虚构数据，不发送商务通知。

## 检查

检查桌面及 375、390、768 像素视口；菜单展开/关闭/Escape；导航标题是否被页头遮住；服务链接是否预选咨询类型；二维码下载与电话链接；表单成功、失败及网络异常提示。手机二维码识别需要人工验证，不以图片可下载替代。

## 配置与发布边界

咨询函数通过平台环境变量 WE_COM_WEBHOOK_URL 获取企业微信通知地址，不在代码或聊天中填写真实值。可选 LEAD_RATE_LIMIT 绑定。未配置渠道时接口返回 503。Python 静态预览不能验证平台绑定或真实通知送达。

不自动提交、推送或部署。远程推送可能触发现有托管发布，必须单独取得授权。原始宣传数字和案例资料保留在 Git 历史中；当前页面改用服务方式与场景说明，待核实数据与展示授权后再加入真实案例。
